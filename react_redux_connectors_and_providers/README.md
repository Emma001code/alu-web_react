# React Redux Connectors and Providers

Holberton School project: connecting React components to Redux with `react-redux`, thunks, DevTools, combined reducers, and selectors.

## Environment

- Ubuntu 18.04 LTS
- Node.js 12.x.x
- npm 6.x.x

## Tasks

| Task | Description |
|------|-------------|
| task_0 | mapStateToProps, Provider, store |
| task_1 | Drawer actions and refactor |
| task_2 | Thunk, login/logout, tests |
| task_3 | Redux DevTools extension |
| task_4 | Root reducer |
| task_5 | Notifications API |
| task_6 | Notification selectors |
| task_7 | Courses API and CourseList |
| task_8 | Reselect memoized selectors |
| task_9 | Notifications container/component |


## Usage

    cd task_N/dashboard && npm install
    cd task_N/dashboard && npm start
    cd task_N/dashboard && npm test
