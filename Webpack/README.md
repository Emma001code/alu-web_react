# Webpack

Holberton School project: module bundling with Webpack, jQuery, Lodash, CSS loaders, and a development server.

## Environment

- Ubuntu 18.04 LTS
- Node.js 12.x.x
- npm

## Tasks

| Task | Description |
|------|-------------|
| task_0 | Basic Webpack setup (no config file) |
| task_1 | Webpack config, production build, Lodash debounce |
| task_2 | CSS and image loaders |
| task_3 | Dev server, modules, code splitting |

## Usage

    cd task_0 && npx webpack
    cd task_1 && npm run build
    cd task_2 && npm run build
    cd task_3 && npm run start-dev
    cd task_3 && npm run build

## Dependencies

- webpack / webpack-cli
- jquery / lodash
- style-loader / css-loader
- file-loader / image-webpack-loader
- html-webpack-plugin / clean-webpack-plugin
- webpack-dev-server
