# React Intro

Holberton School project: introduction to React, components, and testing with Enzyme.

## Environment

- Ubuntu 18.04 LTS
- Node.js 12.x.x
- npm

## Tasks

| Task | Description |
|------|-------------|
| task_3 | Install and configure Enzyme for testing |
| task_5 | Create a React project using Webpack |

## Usage

    cd task_3/dashboard && npm install
    cd task_3/dashboard && npm test
    cd task_5/dashboard && npm install
    cd task_5/dashboard && npm run build
    cd task_5/dashboard && npm start

## Dependencies

- enzyme
- enzyme-adapter-react-16
- webpack / webpack-cli / webpack-dev-server
- react / react-dom
- babel-loader / style-loader / css-loader / image-webpack-loader
